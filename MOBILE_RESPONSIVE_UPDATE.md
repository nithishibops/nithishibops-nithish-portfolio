# Mobile Responsive Update

This build adds production-level phone/tablet responsiveness while preserving the desktop design and premium shine.

Key fixes:
- mobile menu with proper open/close state, Escape support and scroll locking
- safe-area support for modern iPhone/Android devices
- responsive hero typography and profile card
- vertically aligned full-width mobile CTA buttons
- mobile-friendly social links
- compact one-column cards and timeline
- horizontally scrollable project filters
- touch-friendly dashboard links and buttons
- contact text/email wrapping
- centered mobile footer
- back-to-top button positioned above mobile safe area
- hover/shimmer behavior disabled on coarse touch devices to prevent sticky hover states
